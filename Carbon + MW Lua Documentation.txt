Most of the information here will be for Carbon. 
You can pretty much append the phrase "and by extension, MW" onto the end of each sentence, 
as they use basically the same Lua system, and share *most* of the same functions.
Carbon obviously has a lot of functions for Canyon, crews, and other online type game modes and also
Game.QuitToCarClassSelectScreen(), which warps you to the screen where you choose your starter car.

The Basics:
NFSMW and Carbon use BlackBox's modified version of Lua 5.0.1 (*Unsure about ProStreet onwards).
Undercover PS2/Wii (aka Exient Undercover) likely used Carbon's Lua system as a base, though other changes were made, such as new functions, 
renaming existing ones, new stategraphs for takedown, wantedevent and other stuff, and new Mxxxxxxxxxx functions (MNotifyDamageRatio, for example).
You can learn all about the base Lua language here.
https://www.lua.org/manual/5.0/

NOTE:
EVERYTHING is case sensitive.
For example:
Game.JumpToSafehouse() will crash the game.
Game.JumpToSafeHouse() works correctly, it warps you to the safe house.

More Basics:
With MW/Carbon Lua modding, is it's half Lua scripting, half Vault editing.
You can have a perfectly written Lua script, but if you get the vault stuff wrong, at best, the script just wont work, or the game will crash.
These include:

- handler_owner (where the messagehandler node points to)
- message_id (vlt memory dec of internal game function being utilized)
- stateref (in what gameplay state the script is for) (you can check all the gameplay states in gameplay -> baseelement -> state) (these go in the stateref field, for example: stategraph_basicrace_racing)
- transitionlist (what the state will be changed to, if you are changing the state in the lua script) (do not add transitionlist field if state is not being changed)
- Vault (leave as gpcore for general event type logic, or change to gameplayvault of event if it's for a specific event, just like with startgrids and other stuff).

compile command format:
luac -s -o x.blob x.lua

NOTE:
You need to compile them into a .blob (Binary Large Object) file in order to add them through OGVI.
Otherwise you can technically compile them into whatever file format you want (for example: .bin)

decompile command format:
luadec -f -o x.lua x.blob

Alternatively, you can simply drag and drop a bytecode onto the decompiler executeable.

messagehandler nodes:

(Most Wanted 2005)
If the name of your messagehandler node doesn't have any slashes, 
then at the start of the lua source file,
you can simply have the name of the messagehandler node that the bytecode will be attached to.
for example:
name_of_your_node = function(param0, param1, param2)

(Carbon and Exient Undercover) (Unsure about ProStreet onwards)
For Carbon and Exient Undercover, the function header needs to be the VLT Memory HEX of the messagehandler node it's attached to.
It's done in the following format:
h_VLTMEMORYHEX = function(param0, param1, param2)

For example::
wantedevent/stategraph_basicrace_racing_handler_notifymilestoneprogress
VLT Memory HEX is this:
F83F94A3 or 0xF83F94A3 depending on which NFS Hasher was used.
Header looks like this:
h_F83F94A3 = function(param0, param1, param2)

You can use the following tools.
- NFS Hasher v2 by nfsu360 and or NFS Hasher v3 by CiPHER.
- The hasher avaliable within OGVI or Binary/Binarius
- Qalculate! https://qalculate.github.io/ (useful for getting DEC numbers) (Avaliable on Linux, Windows, MacOS)

message_id:
these are Vlt Memory DEC of Mxxxxxxxxxx functions (for example, MTriggerEnter).
These are internal functions that basically determine what the script will be for.
If you're, for example, making a takedown style gamemode, you will need to put
MNotifyVehicleDestroyed into NFS-Hasher v3 and get the VLT Memory DEC, which will be 83708443.
83708443 is what you put as the message_id.
Basically, it will notify whenever a vehicle has been destroyed, and execute any script logic.

The parameters:

With NFSMW/Carbon Lua there are 3 parameters:
- param0.
- param1.
- param2.

In the script, you can re-name them to whatever you want, 
AS LONG as it follows the same order of (param0, param1, param2), 
and they are also applied to functions within the script.
for example:
h_VLTMEMORYHEX = function(vault, specific, context)
h_VLTMEMORYHEX = function(vault, nikki, darius)

param0 refers to gameplay vault (vlt) fields and data.
for example param0.MilestoneName or param0.ThreshholdValue.
This will read the data for the associated fields.

param1 and param2 refer to other types of in game logic, such as context, element and lots more.

The difference between param1 and param2.
Generally speaking, some (but not all) param1 functions can only be used with their corresponding message_id, whereas param2 functions can be used across different scripts.
For example:
- param1.ValueReached can only be used within an MNotifyMilestoneProgress handler (Maybe also MNotifyMilestoneReached, but hasn't been tested).
- param1.Placing can only be used with MNotifyRacePlacement.
- param1.RepPoints can only be used with MNotifyPlayerRep.

Compiler input arguments:
  -        process stdin
  -l       list
  -o name  output to file `name' (default is "luac.out")
  -p       parse only
  -s       strip debug information in dump
  -v       show luac version
  --       stop handling options

Decompiler input arguments:
  -        process stdin
  -d       output information for debugging the decompiler
  -f       decompile multiple files (luadec file1 file2 file3...)
  -o       sets the output file name (default: 'luadec.out')
  -p       only parse file for errors
  -s       strips debug info
  -v       shows luadec version
  --       stop handling options

Here are some game functions that have been documented by rybetasz.
NOTE: Some descriptions have been slightly altered to provide additional information.
Additional functions have also been added and documented.

Game.ShowPauseMenu()                 : Opens the standard in-game pause menu.
Game.ShowTriggerIcon(trigger)        : Displays the interaction icon for a specific world trigger.
Game.HideTriggerIcon(trigger)        : Removes the interaction icon for a specific world trigger.
Game.NotifyCountdownDone()           : Signals the game engine that the start countdown has finished.

[ CATEGORY: RACE & ACTIVITY LOGIC ]
Game.AwardPoints(racerIdx, points)   : Grants a specific amount of points to a racer.
Game.ChallengeCompleted()            : Marks the current challenge/event as successfully finished. Used in MW open world Milestones.
Game.ChallengeComplete(element)      : Marks the current challenge/event as successfully finished. Used in MW and Carbon CS Pursuit races.
Game.UnlockRace(activity)            : Unlocks a specific race event for the player.
Game.NotifyActivityFinished(act)     : Sends a notification that the specified activity is over.
Game.NotifyRaceFinished(element)     : Sends a notification that the specified race/event/activity is over.
Game.AllRacersDone()                 : Returns true if every participant has finished the race.
Game.AllHumanPlayersDone()           : Returns true if all local/online human players have finished.
Game.GetSimTime()                    : Returns the current internal simulation timestamp.
Game.SetRaceExpired()                : Sets the race expired, as if you had run out of time. Useful for setting a lose condition.
Game.AbandonRace()                   : Abandons the current race.
Game.KnockoutRacer(index)            : Knocks out a specific racer, like in Lap Knockout.
Game.TotalRacer(index)               : Destroys a specified racer vehicle.
Game.BlowEngine(element)             : Destroys the engine of a specified element.
Game.ShowGPS(bool)                   : Shows the gps arrow at the top of the screen.
Game.NavigatePlayerTo(goalTrigger, realTarget, maxDeviation, showArrow): The GPS arrow will point towards a specific trigger or marker. Use the format (goalTrigger, goalTrigger, maxDeviation, showArrow) to skip needing a marker.
RaceStatus:SetHasBeenWon(bool)       : Sets whether the race is marked as won or not. 
RaceStatus:SetIsRestartAllowed(bool) : Enables or disables the ability to restart the race/event.
RaceStatus:SetActivelyRacing(bool)   : Sets whether the player is racing or not.
RaceStatus:ClearCheckpoints()        : Clears all current event checkpoints.
RaceStatus:ResetRaceData()           : Resets all current race data.
RaceStatus:SetRoaming()              : Sets the player in free roam mode.

[ CATEGORY: RACER & PLAYER SENSORS ]
Game.GetRacerIndex(element)          : Returns the index ID of a specific racer object.
Game.GetPlayerElement(index)         : Returns the object/entity associated with a player index.
Game.GetRacerElement(index)          : Returns the object/entity associated with a racer index.
Game.GetRacerCharacter(index)        : Returns the character profile ID assigned to a racer.
Game.RacerIsHuman(index)             : Checks if the specified racer is controlled by a human.
Game.PlayerIsLocal(index)            : Checks if the player is on the local machine (not network).
Game.SimableDistance(elem, marker)   : Calculates the distance between an object and a world marker.
Game.SimableAngle(elem, marker)      : Calculates the relative angle between an object and a marker.
Game.GetSimableSpeedKmh(element)     : Returns the speed of an element in Kilometres Per Hour.
Game.GetRacerPctComplete(index)      : Returns the percentage complete of a specified racer.
Game.AllowFinishLine(bool)           : Allows or disables the finish line.
Game.EnableTrigger(triggername, bool): Enables or disables a specific trigger. Useful for disabling a trigger, then enabling it once a condition has been met.

[ CATEGORY: POLICE & WORLD ]
Game.SetWorldHeat(heat level)        : Sets the heat level of your current vehicle to a specified heat level.
Game.ForcePursuitStart(heat level)   : Forces a pursuit start of a specified heat level. leave empty to start a pursuit at the players current heat level.
Game.SpawnCop(spawnmarker, pvehicle, inpursuit, inroadblock) : Spawns a specified police vehicle at a specified marker.
Game.SpawnCop(inpursuit, inroadblock) : Spawns a cop near your current vehicle location. The cop will be from your current heat level.
Game.ResetCopsForRestart()           : Clears all active police units to prepare for a race restart.
Game.AwardPlayerBounty(bounty)       : Directly adds bounty points to the player's profile.
Game.WarpToMarkerWhileRoaming(m)     : Teleports the player to a marker during Free Roam mode.
Game.IsActiveSpeedtrap(trigger)      : Checks if a specific speed trap trigger is currently active.
Game.IsActiveMenuGate(trigger)       : Checks if a shop or event entrance gate is active.
Game.ReloadWorld()                   : leave empty to warp to safehouse and respawn at safehouse.
Game.ReloadWorld(param0)             : leave as is to reload and re-start the specific event.
EBailPursuit()                       : Bails the pursuit entirely and clears all active police units. Skips needing to enter and finish cooldown mode.
ECellCall(id number)                 : Triggers a cell phone call of the specified id.
EAddSMS(id number)                   : Adds an SMS of the specified id and shows it to the player. 
Bin.GetNumRacesWon(BinIndex)         : Returns the number of races won for a specified race bin.
Bin.GetNumChallengesPassed(BinIndex) : Returns the number of open world milestones that have been completed for a specified race bin.
Game.GetPlayerBounty()               : Returns the players total amount of bounty for their profile. 
Game.ClearCareerVehicle()
Game.GetStoryLineProgression()
Game.AddvanceStoryLineProgression()
Game.GetWonAttackRacesinArea(AreaName) : Returns the number of races won for a specified map area. Similar to Bin.GetNumRacesWon() but for carbon's map area system.
Game.GetOverAllWonAttackRaces()      : Returns the total number of races won across all areas. Events must be part of a territory zone to count.

Game.AllowEngageEvents(bool)         : Enables or disables the ability to start world events.
Game.AllowMenuGates(bool)            : Enables or disables the ability to enter shops/safehouses.
Game.AllowEngageSafehouse(bool)      : Specifically toggles safehouse interaction.
Game.DoSpecialSetup()                : Executes internal engine-level setup for complex events.
Game.DoSpecialFinalization()         : Executes cleanup and final logic after a special event.
Game.SetTimer(name, interval)        : Creates a custom named timer for script logic.
Game.SkipCareerIntro()               : Forcefully skips the opening cinematics of Career mode.

[ CATEGORY: MUSIC ]

[ CATEGORY: HUD DISPLAYS ]
Debug.ShowScreenMessage(message,)    : Shows a small message display in the bottom right corner, above the speed/tachometer. Can display text, and param0, param1 and param2 functions.
Debug.Print("")                      : Doesn't seem to work in release builds, used during development.
HUD.ShowMessage("MESSAGE_TRANSLATION_NAME") : Displays text in the middle of the screen for 2.5 seconds.
HUD.ShowLoopingMessage("MESSAGE_TRANSLATION_NAME", value to display) : Constantly displays a message on the screen, with a value displayed underneath if assigned. Often used for displaying time remaining.
HUD.HideLoopingMessage()             : Hides any looping messages that are currently active.
HUD.ShowTimeExtension()              : Used for showing time bonus, such as in tollbooth/checkpoint races.
